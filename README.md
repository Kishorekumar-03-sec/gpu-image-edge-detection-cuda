# GPU Accelerated Image Edge Detection using PyTorch (CUDA)

## Project Overview
This project demonstrates GPU acceleration using CUDA through the PyTorch framework. The program performs Sobel edge detection on images using GPU processing in Google Colab.

## Technologies Used
- Python
- PyTorch
- CUDA GPU
- Google Colab
- Matplotlib

## How the Program Works
1. Load an input image
2. Convert the image to grayscale
3. Apply Sobel filters for edge detection
4. Perform convolution operations on GPU
5. Save the edge detected output image

## Files in Repository
- edge_detection_colab.ipynb – Main project code
- GPU_Project_Report.docx – Project report
- sample.jpg – Input image
- edges.png – Output image

## How to Run the Project
1. Open the notebook in Google Colab
2. Enable GPU runtime
3. Run all cells
4. The output image will be generated and saved

## Results
The GPU successfully processes the image and detects edges using Sobel filters.

## Conclusion
This project demonstrates how GPU computing using CUDA can accelerate image processing tasks.
